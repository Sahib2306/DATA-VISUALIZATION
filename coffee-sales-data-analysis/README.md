# ☕ Coffee Shop Sales – Data Visualization Project

This project focuses on analyzing **Coffee Shop Sales data** and creating insightful **data visualizations** to understand sales trends, customer behavior, and product performance.

The dataset contains transaction details from a coffee shop, including date, time, product category, store location, quantity, and sales amount.  
Using Python, this project uncovers key patterns that help in business decision-making.

---

## 📂 Project Files

📁 coffee-shop-sales-visualization
│── 📄 coffee_shop_sales_visualization.ipynb   # Main notebook with analysis & visualizations
│── 📄 Coffee Shop Sales.xlsx                  # Dataset used for analysis
│── 📄 requirements.txt                        # Python dependencies
│── 📄 README.md                               # Project documentation

---

## 🚀 Features of This Project

### ✔ Data Processing
- Loading and cleaning Excel data  
- Handling missing values  
- Converting date/time columns  
- Creating new features such as:
  - Day of week  
  - Month  
  - Hour of sale  

### ✔ Visualizations Included
- Sales over time (line plot)  
- Revenue by product category (bar chart)  
- Top-selling products  
- Transactions by hour (histogram)  
- Weekday vs Hour heatmap  
- Store-wise performance comparison
